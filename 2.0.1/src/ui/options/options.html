대시보드

DC Ultimate 확장프로그램 상태 및 활성화된 모듈 개요입니다.

확장프로그램 상태

DC Ultimate 엔진 v1.0.0이 정상적으로 실행 중입니다.

자동화 상태

모니터링 루프가 활성화되었습니다.

일반

핵심 브라우징 동작 및 확장프로그램 상호작용을 구성합니다.

브라우징 동작

자동 새로고침 (초)
일정 간격으로 갤러리 목록을 자동으로 새로고침합니다. 0으로 설정하면 비활성화됩니다.

인터페이스

DC 야간모드 연동
위쪽 테마 선택(시스템/라이트/다크)을 디시인사이드 야간모드에도 그대로 적용합니다. 디시 페이지에서 야간모드 버튼을 눌러도 확장프로그램 테마가 함께 바뀝니다.
확장프로그램 아이콘 동작
확장프로그램 아이콘을 클릭하면 팝업 대신 사이드 패널이 바로 열립니다.

읽기 및 레이아웃

팝오버 및 고급 레이아웃으로 읽기 경험을 향상시킵니다.

미리보기 팝오버
게시글 제목에 마우스를 올리면 클릭하지 않고도 내용을 미리 볼 수 있습니다.
다단 읽기 레이아웃
넓은 화면에서 목록, 게시글, 댓글을 나란히 배치합니다.

미디어 갤러리

일괄 다운로드 및 원본 이미지 보기 옵션입니다.

미디어 갤러리 도구
원본 이미지 팝업, 일괄 선택, 중복 이미지 감지 기능을 제공합니다.

서명 이미지 자동 첨부

게시글 작성 시 상단에 서명 이미지(자짤)를 자동으로 삽입합니다.

자짤을 여러 장 등록하고 랜덤 / 지정 1개 / 갤러리별로 쓰는 설정은 사이드패널 [작성] 탭에서 관리합니다. 이 화면에서 저장하면 목록에 한 장이 추가됩니다.
자동 첨부 사용
새 글을 작성할 때 설정된 이미지를 에디터에 자동으로 삽입합니다.
서명 이미지 (자짤)
사용할 이미지를 선택하세요. 확장프로그램 저장 공간에 저장됩니다.
등록된 서명 이미지가 없습니다.

DC 로그인

로그인이 풀렸을 때 저장된 계정으로 자동 로그인합니다.

자동 로그인

자동 로그인 사용
디시인사이드 페이지에서 로그아웃 상태가 감지되면 저장된 계정으로 다시 로그인합니다. 직접 로그아웃한 경우 그 탭에서는 계속 로그아웃 상태로 두고, 새 탭이나 다른 사이트를 거쳐 다시 들어올 때 자동 로그인합니다.
비밀번호 변경 안내 건너뛰기
로그인 후 비밀번호 변경 안내가 뜨면 [나중에 변경]을 자동으로 선택해 바로 로그인 상태로 진입합니다.

보안 안내

아이디와 비밀번호는 이 브라우저 프로필의 확장프로그램 저장소(chrome.storage.local)에 암호화 없이 저장되며, 저장된 값은 sign.dcinside.com 로그인 폼에만 입력됩니다. 공용 PC에서는 사용하지 마세요.
보안문자(캡차)나 추가 인증이 요구되면 자동 로그인은 즉시 중단되고 직접 로그인해야 합니다. 연속 3회 로그인에 실패하면 계정 잠금을 막기 위해 자동 로그인이 자동으로 멈춥니다.
